## Setup

1. Create a PUBLIC GitHub repository named `LeetCode-DSA`.
2. Upload the included `README.md`.
3. Install a currently working LeetCode-to-GitHub sync extension such as LeetHub v2.
4. Open the extension and choose `Authorize with GitHub`.
5. Approve GitHub access.
6. Select/connect the `LeetCode-DSA` repository.
7. Open LeetCode and submit a problem.
8. After an Accepted submission, check the GitHub repository.

Important:
- You must personally approve the GitHub authorization.
- Never share your GitHub password or access token with anyone.
- If auto-sync fails with the current LeetCode layout, use the extension's manual-sync option (if available) after an accepted submission.
